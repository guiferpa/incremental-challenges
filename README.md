# Challenges

A collection of coding challenges for study, ordered from easiest to hardest.

Each challenge describes a problem, not an implementation. Solve it in any language you like.

## Challenges

| # | Challenge | Difficulty | Time | Topics |
| --- | --- | --- | --- | --- |
| 001 | [Log Parser](challenges/001-log-parser.md) | Beginner | 60 min | Strings, parsing, aggregation |
| 002 | [Key-Value Store](challenges/002-key-value-store.md) | Beginner | 60 min | Hash maps, stacks, transactions |
| 003 | [Banking System](challenges/003-banking-system.md) | Intermediate | 75 min | Data modeling, sorting, scheduled events |
| 004 | [Rate Limiter](challenges/004-rate-limiter.md) | Intermediate | 75 min | Hash maps, time windows |
| 005 | [LRU Cache](challenges/005-lru-cache.md) | Intermediate | 75 min | Hash maps, linked lists, eviction |
| 006 | [Task Scheduler](challenges/006-task-scheduler.md) | Advanced | 90 min | Heaps, dependencies, simulation |
| 007 | [Artifact Registry](challenges/007-artifact-registry.md) | Advanced | 90 min | Graphs, cycle detection, TTL, snapshots |
| 008 | [Map Game Engine](challenges/008-map-game-engine.md) | Expert | 120 min | Trees, traversal, state inheritance |
| 009 | [Order Book](challenges/009-order-book.md) | Expert | 120 min | Heaps, ordered structures, matching |

## Contributing a solution

Put your solution in its own folder:

```
solutions/<github-username>/<challenge-name>/
```

For example: `solutions/guiferpa/001-log-parser/`.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the full steps, rules and the solution README template.
